# HR Path — v2 · "Practice" edition

A second, re-designed version of the HR Path landing page. Same brand, **same copy word for word** — a different visual register.

**Live:** https://mohamed-sr-designer.github.io/hrpath-v2/
**Version 1 (for comparison):** https://mohamed-sr-designer.github.io/hrpath-redesign/

## Why a second version

V1 spoke the visual language of a **software product**: a dashboard hero, a phone mock-up, icon-tile feature cards, consumer-subscription pricing. HR Path does not sell an app — it sells a professional HR outsourcing service. V2 re-registers the whole page as a **professional-services firm**.

| | v1 | v2 |
|---|---|---|
| Type | Baloo Bhaijaan 2 / Poppins (rounded, startup) | IBM Plex Sans Arabic / IBM Plex Sans (institutional) |
| Hero | product dashboard + floating UI chips | a statement of record on letterhead |
| Services | 9 icon-tile cards | numbered capabilities index (01–09) |
| Quality | icon cards | two-column principle rows |
| Compliance | light section | dark ink plate |
| The system | iPhone mock-up with app screens | service records on paper |
| Packages | Netflix-style tiers, gradient ribbon | fee schedule, ascending 2,500 → 3,900 → 4,900 |
| Shape | 18–34px pills, gradients, drop shadows | 3–8px corners, hairline rules, flat brand red |

## Changes in this version
- Client slider: UTG logo removed
- Strategic-partnerships section removed entirely
- Packages ordered ascending in **both** the cards and the comparison table (v1 read 2,500 → 4,900 → 3,900)

## Unchanged
Every headline, paragraph, list item, price, figure and FAQ answer is identical to v1. Bilingual AR/EN, light mode only, per-package CTA opening the glassy lead popup, and the closing lead-generation form all behave as before.

## Stack
Vanilla HTML/CSS/JS, no build step. Serve the folder with any static server, e.g. `npx serve .`
